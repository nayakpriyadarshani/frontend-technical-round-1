The project uses the Google Gemini API for the AI Chat Assistant.

1. Create a Gemini API key.
2. Create a .env file in the project root.
3. Add the following variable:

VITE_GEMINI_API_KEY=your_gemini_api_key

4. Run npm install.
5. Run npm run dev.

The .env file is excluded from Git using .gitignore and the actual API key is not included in the GitHub repository.
